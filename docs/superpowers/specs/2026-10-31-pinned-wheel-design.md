# 轮盘常驻设计

状态：待确认。先于[首次引导](2026-10-31-first-run-guide-design.md)实现。

## 意图

现在轮盘只能用快捷键或鼠标键唤出，用完就消失。用户想让它一直留在屏幕上，随手一点就能打开别的应用：回到桌面时能点，或者在任何应用里都能点。它看起来像桌面小组件，位置可以任意拖动，体验要好。

## 目标

- 新增"常驻"设置，三选一：关闭 / 桌面 / 置顶。默认关闭，老用户不受影响。
- 任意位置按住即可拖动，松手记住位置。
- 原有快捷键和鼠标键唤出照旧。

## 非目标

- 不做系统 WidgetKit 小组件：它不能实时透视液态玻璃，不能任意定位，点击能力也有限。
- 不做多个常驻轮盘，也不做每个桌面空间不同的位置。
- 不改轮盘内容、动画语言和现有唤出流程。

## 反目标（做到了也算失败）

- 想拖动时误打开了应用。
- 常驻窗口挡住下面的点击，比如 640pt 窗口的透明四角吃掉桌面图标或其他应用的点击。
- 空玻璃圆盘、闪烁，或打开时才发现内容是旧的。
- 不用时明显耗电，或留下常驻 perl 进程却没有音乐。

## 用户已决定

- 三种模式：关闭 / 桌面（回到桌面才看得见）/ 置顶（所有应用之上）。
- 用自己的窗口实现，形态像小组件。

## 用户已认可的行为（由我提出）

**拖动**
- 按下后移动不到 4pt，松手算点击；超过 4pt 算拖动，这次不会触发打开、切歌或跳转进度。按在图标上也能拖。
- 轮盘紧跟鼠标，开始时轻微放大并有一下触感，拖动中关闭悬停高亮；松手放稳再有一下轻触感。遵循"减少动态效果"和触感开关。
- 右键轮盘空白处有"锁定位置"，锁定后不能拖，再次右键解锁。默认不锁定。
- 位置重启后不变。显示器拔掉或分辨率变小时，自动移回屏幕内。

**桌面模式**
- 显示完整轮盘，所有普通窗口都在它上面。
- 点应用后轮盘留在原地。
- 只在桌面层显示，每个桌面空间都能看到。

**置顶模式**
- 平时是直径约 44pt 的液态玻璃小圆点，中间是水滴；放音乐时外圈显示进度。
- 鼠标停留约 0.15 秒展开成完整轮盘，路过不触发。移开后稍等收回。
- 点应用后收回成小圆点。
- 小圆点松手后轻轻吸附到最近的屏幕边缘。
- 全屏应用上和每个桌面空间都显示。

**快捷键**
- 置顶模式：轮盘已展开时按快捷键就收起；否则在原来的鼠标位置弹出轮盘，用完消失，小圆点不动。
- 桌面模式：在鼠标位置弹出临时轮盘，桌面上那个不动。

**设置**
- 通用页新增一组"常驻"，放关闭 / 桌面 / 置顶分段控件；菜单栏菜单也能切换。

## 约束

- 不改 bundle id，不重新生成 xcodeproj（新文件手动加入 pbxproj）。
- 透明窗口里不用 `.blur()`。
- macOS 13+；macOS 26 的原生玻璃分支不能被改坏，13–15 走兼容材质。
- 关闭常驻时，现有 `DokWheelWindow` 的唤出路径行为必须完全不变，包括 `Presentation` 状态机。
- 每一步编译、跑 `work/*-test.py`、装到 /Applications；提交和推送要用户明确要求。
- 验证时不要反复在用户屏幕上唤出窗口，见 AGENTS.md 和记忆。
- 新文案要有英文和简体中文，名称末尾不加省略号。
- 所有功能免费。

## 现有代码要注意的地方

- `DokWheelWindow` 是 640×640 无边框窗口，`level = .popUpMenu`；任意外部点击、Esc、点图标后都会 `dismiss()`。`Presentation` 只有 hidden/revealing/shown/dismissing，隐藏时 alpha 为 `windowWarmupAlpha`，还有 0.1s 的可见性守卫和 `order(_:relativeTo:)` 覆写，都假定"只有 showAt 能显示"。
- `appState.selectedIndex`、`selectedRecentAppIndex`、`isMenuVisible`、`centerControlHover` 是全局单份。常驻轮盘和临时轮盘同时存在时会互相串状态。
- `snapshotRecentApps()`、`snapshotNotificationBadges()` 每次唤出取一次；常驻时不会有"唤出"这个时机。
- 音乐的 perl `stream` 只在轮盘显示时运行，隐藏就终止（AGENTS.md：没有常驻 perl 进程）。
- `showAt` 把 640 窗口夹在屏幕内，所以贴边的小圆点不能和展开后的轮盘同心。

## 我的技术决定（请核对）

1. **先做试验**：把现有轮盘窗口放到 `kCGDesktopIconWindowLevel + 1`，确认原生玻璃还能透视壁纸、拖动时不掉帧不闪。试验不通过的回退顺序：换更高的桌面层级 → 桌面模式用次一级的磨砂材质，三个选项照常上线（用户决定）。结果写回本文档后再继续。判定方式：先用 `screencapture` 对比，确认玻璃透出壁纸且没有空盘；最后由用户在真机上看一次，不反复唤出窗口。macOS 13–15 本机测不了，走现有兼容材质，发布说明里写明未实测。次一级材质只用于桌面层窗口，不改唤出轮盘的原生玻璃分支。
2. **常驻用独立窗口和独立的交互状态**，不复用临时轮盘那个窗口，也不共享上面几个全局状态。保留 AGENTS.md 的"唤出轮盘只有一个常驻窗口"规则，常驻是另一扇窗口，把这条规则的例外写进 AGENTS.md。
3. **点击穿透**：鼠标在圆盘和卫星之外时窗口不接收事件，按鼠标位置切换 `ignoresMouseEvents`（全局鼠标移动监听，只在位置跨越边界时写）。
4. **小圆点是单独的小窗口**，展开时显示常驻轮盘窗口，小圆点不隐藏；轮盘开在小圆点旁边，放不下就夹回屏幕内。
5. **内容刷新**：
   - 最近内容和角标：桌面模式在窗口从被遮挡变为可见时（`occlusionState`）取一次；置顶模式在展开时取一次。
   - 音乐：桌面模式只在窗口未被遮挡时运行 `stream`。置顶小圆点需要进度，只在开启置顶且有播放器运行时运行 `stream`，这是"无常驻 perl"规则的一个明确例外，用户主动开启才有；没有播放器时不运行。
   - 被遮挡时暂停进度逐帧动画；小圆点不跑逐帧动画，只低频更新进度。
6. **拖动的归属**：桌面模式拖完整轮盘。置顶模式只拖小圆点，只存小圆点位置。展开时小圆点仍留在轮盘旁边（轮盘开在朝屏幕中央的一侧，不盖住它），随时可以直接拖，一拖轮盘就收回；展开的轮盘本身不能拖（用户试用后改）。鼠标按住时不触发悬停展开。
7. **按住模式和鼠标键**：快捷键或鼠标键弹出的临时轮盘沿用用户设置的点击/按住模式，不改现有逻辑。置顶轮盘已展开时，按下触发键先把它收起，不同时弹临时轮盘。
8. **音乐服务共用**：`NowPlayingService` 仍是一份，`stream` 的启停改成按使用方计数：临时轮盘、常驻轮盘、小圆点各算一个，全部退出才终止，关掉临时轮盘不会断掉常驻的数据。可见的常驻轮盘算"用户正看着"，切歌时照常推入，上一首/下一首锁定也照常。
9. **设置字段**（缺失时回退默认值，兼容旧 settings.json）：常驻模式、桌面轮盘中心、小圆点中心、是否锁定。两种模式的位置分开存。
