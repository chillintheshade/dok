# 首次引导设计

状态：待确认。在[轮盘常驻](2026-10-31-pinned-wheel-design.md)之后实现。

## 意图

用户第一次用 Dok 时最常卡住的是：不知道怎么用快捷键打开轮盘。引导不做讲解，而是让用户亲手按一次、用一次。

## 目标

- 新用户结束引导时，已经亲手用快捷键打开过轮盘，并用它打开过东西或关掉过它。
- 按不出来的人也有路可走。

## 非目标

- 不做多页功能介绍，不放动画教程或视频。
- 不在引导里申请任何权限。

## 反目标

- 用户点几下"下一步"就结束了，其实还是不会用快捷键。
- 快捷键被占用时把用户卡死在引导里。
- 打扰已经在用的老用户。

## 用户已认可的流程

**第一步：按一次快捷键**
- 屏幕中央出现小的玻璃卡片：当前快捷键的大键帽（默认 ⌘ Esc），下面一句"现在按一下试试"。
- 按下修饰键和主键时键帽分别亮起。
- 没有"下一步"按钮，按对了自动进入下一步。
- 约 8 秒没按对，出现"点这里打开轮盘"和"换个快捷键"。

**第二步：用一次轮盘**
- 轮盘弹出，提示"移到图标上，点一下就能打开"。
- 打开任意项目或按 Esc 关掉，都算完成。

**第三步：结束**
- 一句话：快捷键可以在设置里改，轮盘也可以常驻桌面。
- 两个按钮："去设置"和"开始使用"。

**其他**
- 卡片上随时可以"跳过"，跳过也算完成。
- 设置页有"重新查看引导"，放在通用页的系统组。
- 只在首次安装时出现。

## 约束

- 沿用项目约束：不改 bundle id，手动改 pbxproj，透明窗口不用 `.blur()`，文案中英双语且末尾无省略号，遵循"减少动态效果"，macOS 13+。

## 现有代码要注意的地方

- `AppDelegate.showOnboarding()` 现在是一个 `NSAlert`，带"打开辅助功能"按钮，结束后自动弹一次轮盘。要整体替换，相关的 `onboarding.*` 文案一并清理。
- `hasCompletedOnboarding` 已存在。旧版本升级用户已是 true，不会看到引导；但旧 settings.json 缺字段时默认为 false，需要确认有 apps 的老配置不会被当成新用户。
- 引导期间快捷键要走正常的注册路径，保证验证的是真实快捷键。

## 我的技术决定（请核对）

- 卡片是独立的非激活面板，不抢其他应用的焦点。修饰键分别亮起用全局 `flagsChanged` 监听，但先用 `CGPreflightListenEventAccess()` 判断，绝不触发权限弹窗；没有权限时键帽在按对后一起亮，不影响流程。
- 引导始终教键盘快捷键，即使用户设了鼠标键。首次安装默认是点击模式；从设置重看时如果用户是按住模式，第二步的提示改成"按住快捷键，移到图标上，松开就打开"，松开算完成。
- "换个快捷键"就地录入，复用现有录入控件，录好后回到第一步。
- 引导进行中，轮盘的外部点击等行为保持现状；第二步通过轮盘关闭这一事件判定完成。
- 引导中途退出应用，下次启动从第一步重来；只有走完或跳过才写 `hasCompletedOnboarding`。
