# 任务：玻璃优先 + 进度环收尾 + 右键退出 + 轮盘外最近应用

> 交接文档（2026-07-22 第三版，覆盖旧版，旧版作废）。开工前先读 `AGENTS.md`，
> 以及 `docs/plans/2026-07-22-progress-ring-seek-like.md` 的「近期变更」一节。
> 按 0 → A → B → C → D 顺序执行。
>
> **排序理由**：进度环的明暗轻重取决于它背后的玻璃。玻璃先定稿，环再校色，
> 避免在要换掉的背景上白调一遍。

## 任务 0：进度环结构修正（与背景无关的部分，先做）

进度环已按用户要求移到中心区圆形边界（`centerLensRadius` 一圈）。本任务只做
两件与背景无关的修正：

1. **删除环底部多余的线条/刻度**。最终只绘制已播放进度弧；轨道、中心边界、
   进度头部圆点、起点刻度和终点线全部删除。
2. **弧线端帽改圆头**：`StrokeStyle(lineWidth: …, lineCap: .round)`。

⚠️ **明确不做**：进度环的透明度/明暗调整。等任务 A 玻璃定稿后在任务 B 里
统一校准。现在环偏重是已知问题，不要顺手改。

## 任务 A：玻璃观感预设（对照控制中心）

**背景**：底层已是原生 `NSGlassEffectView`（真·液态玻璃采样），但被上层
叠加盖住：`NativeGlassSamplingLayer.applyMaterial` 的黑色 tint
（alpha 0.12 + intensity×0.14，最高 0.26），加 `ControlCenterGlassToneLayer`
三层暗色渐变 + multiply 晕影。结果失去折射与背景透色，观感像磨砂灰塑料。
同壁纸下与系统控制中心并排对比即可复现。

**目标**：交付 2～3 组编译期参数预设，供用户实机对比挑选。

- AGENTS.md 规矩：**保留 NSGlassEffectView 采样层本体**，只调 tint、tone、
  edge 参数。
- 预设建议：
  1. 「控制中心同款」：tint 0～0.06 或 nil，试 `.regular` 风格，tone 层
     opacity 接近 0，multiply 晕影关闭；
  2. 「当前风格」：现参数原样保留作对照；
  3. 「折中」：介于两者之间。
- 用一个编译期常量切换预设（不暴露用户设置项）。交付后**停下等用户实机
  对比选定**；选定后删除未选预设、收敛为最终参数。
- 透明度滑杆（menuOpacity）映射随选定预设重新标定：100% 时应接近所选目标
  观感。
- ⚠️ `work/arcly-glass-appearance-contract-test.py` 锁定了现有参数，需同步
  更新，保持"锁最终值"的意图。

### 定稿结果（2026-07-22）

- 用户实机选定透明度阶梯 3：原生 `.clear`，黑色 tint 基准 `0.03`，不再叠加
  `ControlCenterGlassToneLayer`。
- 保留原生玻璃边缘与单道 `0.55pt` 白色补光。
- `menuOpacity` 在 `0.15...1.0` 内线性映射到材质强度 `0...1`；`100%`
  精确对应选中的定稿观感。
- 编译期预设及桌面实验构建已删除，契约测试只锁定这一套正式参数。

## 任务 B：进度环明暗校准（玻璃定稿后）

在用户选定的玻璃背景上校准进度环层级，基准值（按实际观感微调）：

- 进度弧：`Color.primary` 约 45～55% 透明度；
- 轨道：`Color.primary` 约 8%，与中心圆现有描边视觉融合；
- 不绘制头部圆点；seek 仍由中心边界附近的命中带承载。

保持 `Color.primary` 自适应（浅色模式黑 / 深色模式白），两种外观下都要
目检。不引入任何彩色。尺寸随 `centerMusicControlScale` 缩放。

**任务 B 完成后停下**：跑全部契约测试 + 完整构建，提醒用户安装验收。用户
验收通过并指示后，把进度环 + seek + 玻璃的全部改动作为一个 commit 存档
（此前一直未提交），再开始任务 C。

### 实现结果（等待实机验收）

- 所有状态都不绘制中心边界，未播放段也不另绘轨道。
- 已播放段线宽限制在 `0.9...1.0pt`，透明度 `0.28`；不绘制头部圆点。
- `NowPlayingService.playbackProgress(at:)` 维护实际显示基准：小于 `1.5s` 的
  helper 双向偏差每次只吸收 `8%`，避免进度弧周期性前蹦或后退；切歌、播放状态
  变化、seek 和大幅跳转仍可重置。

## 任务 C：右键退出（极简版）

**目标**：右键**运行中的 App 槽位**弹出仅含一项「退出」的菜单；其余一切
右键行为维持现状（关闭轮盘）。

- 命中判定：`ArclyWheelWindow` 的 `localRightClickMonitor` 先复用
  `updateSelection` 的扇区/半径逻辑判定是否命中槽位；命中且
  `app.itemType == .app` 且 `app.isRunning` → 弹 `NSMenu`（一项：`退出`，
  执行 `NSRunningApplication.terminate()`）；其余情况（未运行的 App、
  文件/文件夹槽位、中心区、空白、窗口外）→ 关闭轮盘，与现状一致。
- 菜单弹出期间挂起全局 click/move 监听（否则 global click monitor 会立刻
  关掉轮盘）；菜单收起后恢复；执行「退出」后关闭轮盘。
- 菜单文案走 `Loc.string`，en + zh-Hans 同步新增。
- hold 模式下行为一致；菜单打开期间 hotkeyUp/mouseUp 不触发启动。
- 本任务刻意做最小集。「在访达中显示 / 移除 / 隐藏」等项将来再议，不要
  顺手加。

### 实现结果（等待实机验收）

- 悬停与右键共用同一套槽位半径和扇区命中计算。
- 仅运行中的 App 槽位弹出一个本地化「退出」菜单项；其他右键仍关闭轮盘。
- 菜单跟踪期间暂停全局移动/点击监听，并阻止 hold 模式的快捷键或鼠标松开启动
  槽位；菜单取消后恢复监听，执行退出后关闭轮盘。

## 任务 D：最近应用 —— 轮盘外卫星方案

**背景决策**：最近应用**不进轮盘**。占用扇区会挤压固定槽位、抢视觉重心，
用户已否决轮盘内方案。改为"卫星"：贴着轮盘外缘下方的一小段弧。

**形态**：

- 最多 4 个（默认 2）小图标，尺寸约为主槽位图标的 0.75 倍，各自坐在小圆形
  玻璃底座上（材质做法与主盘一致或用系统 material 圆底，观感须与任务 A
  选定的玻璃预设协调），右下角小时钟角标标识动态身份。
- 排布：以 6 点钟方向为中心、沿 `outerRadius + 10~14pt` 的弧线对称展开，
  间距均匀。视觉上从属于轮盘，不遮挡中心歌名与下方槽位。
- 出现/消失动画与轮盘主体一致（跟 `isMenuVisible` 走）。

**行为**：

- MRU 追踪：`NSWorkspace.shared.notificationCenter` 监听
  `didActivateApplicationNotification`，维护去重列表（上限 10），排除已固定
  在轮盘上的 App 与 Arcly 自身；持久化到 `AppSettings`（新增字段走容错解码
  默认值，兼容旧 settings.json）。
- **快照原则**：`showAt` 时快照，轮盘可见期间内容绝不变化。
- 历史不足时该卫星**直接隐藏**（卫星不影响主盘几何，无需占位）。
- 点击 = 激活/启动，与 App 槽位一致；hold 模式甩到卫星上松手同样生效。
- 命中判定：卫星各自为独立圆形命中区（中心角度 + 半径带），判定顺序先于
  "distance > outerRadius 取消选中"；选中态给轻微放大反馈，风格与主槽位
  一致。
- 设置：「轮盘」tab 加独立显示开关和 1～4 数量控件（默认开启、2 个），布局不得破坏
  920×520 契约。
- 窗口尺寸：如需容纳卫星，允许适度增大 `ArclyWheelView.windowSize`（保持
  正方形、居中与屏幕边缘 clamp 逻辑），并在**最大半径设置**下验证卫星不
  越界、不被裁切。

### 实现结果（等待实机验收）

- 监听系统应用激活事件，最近记录去重后持久化最多 10 条；Arcly 自身和固定
  轮盘 App 不进入记录，旧设置缺少字段时默认显示 2 个卫星。
- 每次轮盘唤出前生成最多 4 个最近应用快照；轮盘显示期间后台 MRU 更新不会改变
  当前卫星内容。
- 卫星使用主图标 0.75 倍尺寸、独立原生玻璃圆底和时钟角标，沿同一圆弧排布；
  3～4 个卫星时略微加宽角间距，避免图标和状态标记显得拥挤。
  运行中的卫星显示黑点，右键复用运行中固定槽位的单项「退出」菜单。
- 最大轮盘半径下由 640pt 正方形透明窗口完整容纳。
- 卫星圆形命中优先于主盘外缘清空逻辑；点击和 hold 松开都复用固定槽位启动路径。
- 设置页增加独立显示开关和 1～4 分段控件；同时修正选中扇形内缘，使其跟随动态中心圆尺寸，
  调整半径或图标大小后不再侵入中心区。

## 槽位通知角标（2026-07-22）

- 轮盘每次唤出时通过 Dock 的辅助功能结构读取一次 `AXStatusLabel` 与 `AXURL`，
  生成固定槽位和最近应用卫星共用的角标快照；显示期间不刷新、不后台轮询。
- 查询限制在约 `100ms` 内，未授权、超时或系统结构变化时静默降级为无角标，
  不弹额外权限提示。
- 已知限制：角标只对运行中的 App 存在；Dock 的辅助功能层级属于系统实现细节，
  后续 macOS 变更该结构时应继续优雅降级为无角标。
